The module follows Next.js App Router conventions: `layout.tsx` is the root layout that injects global fonts, PWA registration, AuthCookieMigration, AuthProvider, and SessionProvider around all children; `manifest.ts` declares the PWA manifest. Client pages live under `app/<route>/page.tsx` and are marked with the `'use client'` directive, using React hooks (`useState`, `useEffect`, `useRef`) and Next navigation (`useRouter`, `useSearchParams`). The real-time booth lives in `room/[code]/page.tsx`, which instantiates a `RoomEngine` (from `@/lib/rtc/engine`) to coordinate WebRTC peer streams, countdowns, and shot synchronization across up to four participants. Server endpoints are colocated under `app/api/*/route.ts` and each exports `runtime = 'nodejs'` plus `dynamic = 'force-dynamic'`; they authenticate via Supabase session or admin clients and enforce ownership through RLS. The `auth/callback/route.ts` handles PKCE code exchange and OTP verification redirects. Cron-style background jobs (`api/reminders/route.ts`, `api/retention/route.ts`) are protected by a `CRON_SECRET` bearer token and use `createAdminClient` for service-role access.
