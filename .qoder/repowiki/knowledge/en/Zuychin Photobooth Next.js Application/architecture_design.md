The root orchestrates four child layers through a single Next.js App Router entry point: `app_pages_and_api` provides the page/API routes, `shared_components` supplies React UI primitives, `domain_lib` exposes client-side camera/media/push/session utilities, and `public_assets` serves static files plus the service worker. All server requests pass through `proxy.ts`, which is Next.js 16's replacement for `middleware` and refreshes the Supabase session cookie via `@supabase/ssr` so Server Components read a valid user. The database schema in `supabase-setup.sql` defines the canonical contract (profiles, couples, strips, relays, photo dates, push subscriptions) with row-level security policies that both API routes and storage bucket policies enforce. Environment variables `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY` are the sole runtime wiring between the app and Supabase; Cloudinary and web-push are optional integrations consumed through the same API layer.
