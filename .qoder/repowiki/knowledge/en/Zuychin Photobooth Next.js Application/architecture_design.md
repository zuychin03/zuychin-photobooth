The root project is a single Next.js 16 monorepo entry point that composes four child layers: `app_pages_and_api` exposes the App Router pages and API routes, `shared_components` provides reusable React client UI primitives, `domain_lib` exports flat client-side modules for camera capture, media processing, cloud storage, push notifications, and session utilities, and `public_assets` serves icons, stickers, ML models, MediaPipe WASM bundles, and the service worker. All server requests flow through `proxy.ts`, which replaces Next.js 16's `middleware` convention to refresh the Supabase session cookie via `@supabase/ssr` before any Server Component or API route runs. The database schema in `supabase-setup.sql` defines the canonical contract (profiles, couples, strips, relays, photo dates, push subscriptions) with row-level security policies that both API routes and storage bucket policies enforce. Environment variables `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY` are the sole runtime wiring between the app and Supabase; Cloudinary and web-push are optional integrations consumed through the same API layer.
