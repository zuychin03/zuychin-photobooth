This module is a flat collection of browser-served resources consumed by the Next.js frontend. It contains three layers: (1) PWA identity files at the root (`favicon.svg`, `zuychin-logo.svg`, `icon-192.png`, `icon-512.png`, `icon-512-maskable.png`, `apple-touch-icon.png`) consumed by the `<head>` manifest; (2) runtime assets grouped by feature — `models/selfie_segmenter.tflite` for on-device segmentation, `mediapipe/wasm/` for the Vision JS/WASM runtime, and `stickers/{3d,flat}/` for overlay graphics; (3) the service worker `sw.js` which implements cache-first strategy for static prefixes (`/_next/static/`, `/mediapipe/`, `/models/`, `/stickers/`) and network-first with offline fallback (`/offline.html`) for page navigation. The dependency direction is one-way: the browser loads these assets; nothing in this directory imports from the rest of the codebase.
