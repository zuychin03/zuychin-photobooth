Flat collection of independent React Server Components marked with `"use client"` that each encapsulate a single UI concern. Components compose each other through props rather than shared state: `RoleCapture` orchestrates the multi-shot capture by composing `CameraPreview`, `Countdown`, and `CaptureFlash`; `FilterBar` renders filter buttons driven by the shared `FILTERS` config from `@/lib/filters`. Browser APIs (MediaDevices, Service Worker, Push API, beforeinstallprompt) are accessed inside `useEffect` hooks so the components remain pure renderers. Each component is self-contained - no internal subdirectories, no shared types file - and depends only on sibling components or `@/lib/*` / `@/hooks/*` modules, keeping dependency direction strictly inward toward application libraries.
