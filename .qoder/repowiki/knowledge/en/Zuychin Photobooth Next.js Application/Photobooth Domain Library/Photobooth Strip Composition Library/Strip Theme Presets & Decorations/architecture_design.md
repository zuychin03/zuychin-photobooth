Single-file module exporting two data interfaces - `ThemeDecor` (per-sticker position/scale/rotation in normalized 0..1 coordinates relative to strip size) and `ThemeDef` (bundle of frameId, patternId, stickerStyle, optional caption, and a decor array). A constant `THEMES` array registers six built-in presets (birthday, love, party, cinema, cute, garden), each composed of a frame slug, a procedural pattern id, a sticker style from `./decor`, and six corner/edge/footer decorations placed with organic tilt via the shared `D = 0.26` radian constant. The only runtime API is `getTheme(id)`, which performs an exact-id lookup and returns null for missing/undefined ids, keeping the module read-only and side-effect free.
