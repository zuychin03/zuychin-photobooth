Single-file module exporting a `PatternDef` interface (`id`, `name`, `draw(ctx, w, h, ink)`) and a static `PATTERNS` array of concrete pattern implementations. Each `draw` function uses the passed `ink` color with a fixed low `globalAlpha` (0.08–0.14) so the texture tints any frame color without overpowering captions. Deterministic scatter patterns (`confetti`, `stars`) use a seeded `mulberry32`-style `rand(seed)` generator to guarantee identical preview/export rendering. Two private path helpers (`heartPath`, `sparklePath`) are reused across patterns. A single `getPattern(id)` lookup returns a `PatternDef` or `null`. There is no theme layer in this file - themes are composed elsewhere by pairing a pattern with preset decorations; plain strips remain the default when no pattern is selected.
