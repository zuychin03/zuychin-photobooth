The library is a flat set of sibling modules with strict one-way dependencies centered on `compose.ts` as the rendering orchestrator. `layouts.ts` provides the canonical geometry constants and `StripLayout` registry that every other module consumes; `compose.ts` reads those layouts, applies filters, overlays stickers from `sticker-assets.ts`, draws backdrops via `scenes.ts`, and uses style data from `decor.ts`. The new `patterns.ts` and `themes.ts` modules feed into composition through the same layout/theme contracts so procedural ink-tinted patterns and preset themes are interchangeable at render time. `couple.ts` and `streak.ts` are independent persistence/utility layers consumed by the UI layer rather than by composition itself. Dependency direction is strictly inward: `compose` → (`layouts`, `filters`, `decor`, `sticker-assets`, `scenes`, `patterns`, `themes`), `sticker-assets` → `decor`; no sibling imports each other beyond these edges, keeping the renderer composable and testable.
