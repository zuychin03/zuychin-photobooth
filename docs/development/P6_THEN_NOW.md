# Then & Now domain contract

Recorded 23/09/2026. `lib/memories/then-and-now.ts` supplies the bounded T5 reference and drawing primitives. The local booth, project persistence and comparison export now use these primitives. [P6 evidence](P6_EVIDENCE.md) records the native import, crop, reload, next-round and GIF checks, separately from the domain tests below. Physical camera alignment and device acceptance remain pending.

`ThenNowPlan` contains `version:1`, `reference:{mediaId,provenance,date,crop}`, `alignment:{zoom,offsetX,offsetY,rotation,mirror}` and `ghostOpacity`. Provenance is one of project-original, project-strip, imported-image or imported-strip. Project sources also name their project and source media IDs. These are descriptive provenance fields, never access grants. The caller must obtain the source through its currently authorised scoped repository and copy its encoded original into the destination project's own inventory. No network fetch or permission inference exists here.

Reference dates are fixed ISO calendar days or null. Unknown dates stay labelled **Unknown date**, including imported images. `thenNowDateFromInstant` converts an explicit timestamp using the supplied capture timezone, with no current-time fallback. A flattened strip requires an explicit normalised selection rectangle and renders **Whole strip reference** for a full-image selection or **Selected strip crop** for a smaller selection. It never becomes an inferred original photograph. Strict validation rejects arbitrary fields, URLs, accessors, unsupported provenance, invalid calendar days and out-of-range geometry.

The root integration owns an optional `editor.thenNow` and one separate media kind `reference`, with `participantId:null`. The reference must consume the existing 24-file, 64 MiB encoded and 48 MiPixel aggregate project budgets, with existing 10 MiB/4096-edge/12 MiPixel per-photo limits. It must not join participant source order, change `capturedAt`, or replace captured originals. Removing the plan should use existing reference accounting/history rules rather than independently deleting shared inventory. Portable import/export retains bytes and descriptive provenance, without treating old project IDs as permission.

## Drawing and ownership

`drawThenNowGhost(ctx,referenceCanvas,plan,rect)` uses the full reference canvas. It applies the selected crop, then the same `photoPlacement` cover/zoom/offset/right-angle-rotation/mirror geometry used by the compositor. Opacity is explicit from zero to one and the caller's context state is restored.

`drawThenNowComparison(ctx,referenceCanvas,currentCanvas,plan,{width,height,currentDate,currentAlignment?})` draws two dated panels. `drawThenNowAlternatingFrame` has the same arguments plus a `then|now` phase before options and supplies deterministic dated motion frames. Neither encodes files, runs an animation timer nor allocates another decoded image. The caller owns both sources and the output canvas. Rendering never resizes or disposes them. Use `thenNowOutputSize(width,aspect,mode)` to calculate the canvas, then spread its width, height and aspect into drawing options. The helper preserves the exact photo aspect and reduces width when needed to remain inside 2048 pixels per edge and 4 MiPixels. Output width is at least 320 pixels. Margins, footer and typography scale with width, giving comparison labels 12 pixels when displayed at 320 pixels wide; alternating frames use a slightly larger scale. Both dates may be unknown. Preview and final output should use the same aspect ratio and alignment for a faithful ghost guide.

The optional `prepareThenNowReference(blob,plan,{signal})` is for standalone consumers that do not already have the session decoder's reference canvas. It checks image signatures/dimensions, performs native decoding, verifies decoded dimensions, retains at most a 1024-edge owned preview and closes the bitmap. The original Blob is unchanged. Call its idempotent `dispose()` when finished. Injected decoder/canvas ports are for tests and must return owned resources.

Only one standalone preparation is allowed at once. Cancellation or a ten-second timeout rejects the caller promptly, but holds the allocation slot until the underlying native decode actually settles. A late result is disposed and never published. Browser native allocation cannot be aborted; a permanently stalled decode consequently keeps this helper unavailable rather than accumulating more decoders. The preferred integrated path is the existing session-owned decoder plus the pure drawing functions, avoiding duplicate reference decoding.

## Evidence

Ten focused Node tests cover strict provenance, mandatory strip crops, fixed dates including timezone rollover, compositor-equivalent geometry, identical ghost/comparison crop placement, unknown-date/crop labels, exact output aspect and scaled label readability, output bounds, original-byte preservation, idempotent disposal and cancellation while decoding is outstanding. Drawing tests use a recording canvas to inspect source rectangles and transforms; they do not prove native pixels or visual quality. Native browser rendering, capture alignment, saved project reload, portable bundles and alternating encoded exports remain integration checks owned by the parent task.
