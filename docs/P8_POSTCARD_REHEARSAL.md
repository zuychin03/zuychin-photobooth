# Remote postcard rehearsal

The development-only `/v2-lab/events/postcards` route runs the real composer, guest runtime, postcard clients, IndexedDB journals and native image encoder against an isolated in-memory transport. It uses two synthetic source principals and separate synthetic event guest identities. It never calls a provider or changes hosted data.

Start the rehearsal as A, connect and create a postcard. Give submission permission. Switch to B and connect to join the same immutable proposal, then give permission. Switch back to A and connect, prepare the full synthetic PNG and send it. Release verification explicitly, refresh, and review and approve the exact JPEG as each contributor. Gallery and wall permissions begin false and require unanimous choices. Their final states remain subject to host approval.

Failure controls lose ticket, permission or reservation acknowledgement after the synthetic server accepts the operation. Remount retains the server and scoped journal. Ticket and reservation retries retain their original IDs. Switching roles closes the previous mounted runtime and source lifetime. External withdrawal revokes every contributor's access to the derivative. Stop and clear removes the synthetic server records and both uniquely named databases.

The native strip probe checks preserved dimensions and the two coloured end bands. The native journal probe checks remount identities, guest isolation, stale revision refusal, the shared eight-entry limit and token/photo-free recovery records; its unique database is deleted afterwards. Probe results must be observed in the browser before claiming native evidence.

Source checks: six focused encoder/transport regressions pass, including over-10-MiB PNG header acceptance, JPEG's 10-MiB input bound, exact reservation recovery, separate guest authority, verified JPEG bytes, unilateral approval remaining pending and external withdrawal blocking approval. PNG inputs allow up to16MiB, output JPEG up to2,000,000 bytes, identical dimensions up to4096 pixels per edge and12 megapixels. No rescaling or cropping is used.

The synthetic transport models protocol and failure cases. It does not replace disposable PostgreSQL tests, real worker verification or native walkthrough evidence. Public hosting and flags remain unchanged.
